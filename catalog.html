CNC Machine Brands & Models

Brand / Model Description Era Status
Haas (VF Series) US-made vertical machining centers, a mainstay of job shops and schools worldwide. 1988–present Active
Fanuc (controllers & robots) Japanese giant known for CNC controllers, servo drives, and industrial robots. 1956–present Active
Bridgeport (Series I mill) Classic manual/CNC-retrofit knee mill; the archetypal machine shop mill. 1938–2000s (brand persists) Legacy
Tormach (PCNC 440/770/1100) Affordable benchtop/personal CNC mills popular with hobbyists and small shops. 2005–present Active
ShopBot (PRSalpha, Desktop) CNC routers for woodworking, sign-making, and prototyping. 1996–present Active
Bantam Tools (Desktop CNC Milling Machine) Small-format desktop CNC mill aimed at makers, PCB prototyping, and education. 2014–present Active
Denford (Novamill, Orac, Triac) UK manufacturer of educational and light-industrial CNC machines. 1980s–present Active
Sherline (5400/5800 mills & lathes) Small precision manual and CNC-ready mills/lathes for hobby machinists. 1974–present Active
Okuma (LB, MB, Genos series) Japanese builder of CNC lathes and machining centers with proprietary OSP controls. 1898 (co.), CNC era 1970s–present Active
DMG MORI German/Japanese joint brand producing high-end turning and milling centers. 2009–present (merger) Active
Mazak Long-running Japanese CNC machine tool builder (lathes, mills, multitasking machines). 1919 (co.), CNC era 1970s–present Active

Historical & Legacy CAM / CNC Control Software

Software Description Era Status
Mastercam One of the longest-running commercial CAM packages for milling, turning, and more. 1983–present Active
Mastercam X (X, X2...X9 series) The "X" generation UI overhaul of Mastercam, widely used through the 2000s–2010s. 2006–2015 Legacy
SolidCAM CAM software tightly integrated inside SolidWorks, known for iMachining strategies. 1995–present Active
Mach3 Hugely popular PC-based motion controller software for hobby/light-industrial CNC. 2001–present (superseded by Mach4) Legacy
Mach4 Successor to Mach3 with a more modern, modular architecture. 2014–present Active
LinuxCNC (formerly EMC2) Open-source real-time CNC control software running on Linux with RTAI/RTLinux/PREEMPT_RT. 1990s (as EMC)–present Active
GRBL Lightweight open-source G-code interpreter/motion controller firmware for Arduino-class boards. 2009–present Active
EdgeCAM CAM software for milling and turning, later absorbed into the Hexagon/Vero portfolio. 1985–present Legacy
Vectric Aspire / VCarve Popular CAM software for CNC routers, focused on woodworking, signage, and artistic carving. 2005–present Active
SprutCAM Russian-developed multi-axis CAM software, known for robotics and complex milling/turning. 1991–present Active
FeatureCAM Feature-recognition based CAM software, later acquired by Autodesk. 1995–present (Autodesk-owned) Legacy
WinPC-NC German-made PC-based CNC control software popular with hobby routers/mills in Europe. 1990s–present Active
TurboCNC DOS-based CNC motion control software, a fixture of budget hobby retrofits in the 90s. 1993–2000s Legacy
BobCAD-CAM Entry-level to mid-range CAM software bundle for mills, lathes, and routers. 1985–present Active
KCam Simple Windows CNC control software popular for small hobby mills/routers in the 2000s. Late 1990s–2010s Discontinued
CamBam Lightweight, affordable 2.5D/3D CAM software popular with hobbyists. 2008–present Active
ArtCAM Relief/3D artistic CAM software for engraving and sign-making, later folded into Autodesk then discontinued. 1995–2018 Discontinued
Mecsoft (VisualMILL / RhinoCAM) CAM plug-ins/standalone products, notably RhinoCAM for Rhino3D users. 1998–present Active
Delcam PowerMILL High-end 5-axis CAM software for complex/aerospace machining, acquired by Autodesk in 2018. 1988–present (Autodesk-owned) Legacy
Fusion 360 CAM Autodesk's cloud-connected CAD/CAM/CAE package with integrated milling/turning CAM. 2013–present Active
PathPilot Linux-based CNC control software developed by Tormach for its machines. 2015–present Active
UCCNC Motion control software paired with CNC Drive's UC100/UC300 USB motion controllers. 2013–present Active

Status key: Active = currently developed/sold, Legacy = superseded but still used/supported in some form, Discontinued = no longer developed or sold.
